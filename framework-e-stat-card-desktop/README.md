## 적용한 규칙

| 구분 | 규칙 | 이 화면에서 |
|---|---|---|
| Typography | `(size − 1) × 0.83vw + 1rem`, size ≤ 1rem 은 px 고정 | 가변: 숫자 72(토큰 없음) · H3 40 · P2 16 / 고정: P3 14 |
| mid-N | `(N − 8) × 100vw / 1920 + 8` | 섹션 상하 120, 텍스트 ↔ 카드 40, 텍스트 간격 16, 카드 패딩 40, 카드 안 간격 32 |
| vw-N | `N × 100vw / 1920` | 카드 간격 vw-16 (시안) · 카드 패딩은 데모에서 vw-40 과 비교 |
| 좌우 마진 | global/desktop-margin-vw = 19 | 1vw |
| 카드 | 3개 균등 분할 · radius 8 | 선은 레이아웃 밖(카드 높이 254 = 패딩 + 내용) → 안쪽 그림자 1px 로 그려 패딩 = 토큰 |

## 데모 패널 (우측 상단)

- **card gap** — `vw`(시안) / `mid` 전환 + 값 N (기본 16). 옆에 실제 px
- **card padding** — `mid`(시안) / `vw` 전환 + 값 N (기본 40). 옆에 실제 px
- **cards** — 3개(시안) / 4개 (시안에 숨겨진 4번째 카드)
- **reset** — 모두 시안 값으로
- 하단에 카드 크기 · 패딩 · 안쪽 폭 · 숫자 넘침 여부 · 설명 줄 수를 표시합니다
