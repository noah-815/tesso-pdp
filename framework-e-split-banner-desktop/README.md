## 적용한 규칙

| 구분 | 규칙 | 이 화면에서 |
|---|---|---|
| Typography | `(size − 1) × 0.83vw + 1rem`, size ≤ 1rem 은 px 고정 | 가변: H3 40 · 로고 20 / 고정: 오버라인 · 설명 14, 버튼 13 |
| mid-N | `(N − 8) × 100vw / 1920 + 8` | 섹션 상하 20, 내용 좌우 120, 텍스트 ↔ 버튼 36, 텍스트 간격 12 |
| vw-N | `N × 100vw / 1920` | 섹션 좌우 19 (global/desktop-margin-vw) — 고정, 패널 옵션 없음 |
| em-N | 요소 폰트 크기 기준 | 버튼 13 / 26 (+ 선 1px) |
| 섹션 높이 | 이미지 비율이 정함 | 이미지 941 : 1176, 시안 1216 = 1176 + 상하 20 × 2 |

## 데모 패널 (우측 상단)

각 줄에서 `mid` / `vw` 전환 + 값 N 입력, 옆에 실제 px 표시. mid 에서 8 미만은 값 그대로.

- **섹션 상하** — 시안 mid-20
- **내용 좌우** — 시안 mid-120
- **reset** — 시안 값으로
- 하단에 섹션 높이 · 이미지 크기 · 내용 영역 · 텍스트 폭 · H3 / 설명 줄 수 표시
