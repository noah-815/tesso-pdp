# Framework E · visual banner (variant8) + OverlayCard (Desktop) — 반응형

Figma `14388:294619` · 디자인 기준 폭 1920 · **1rem = 14px**

`index.html` 한 파일과 `assets/`(미디어 이미지, 미디어 마스크)로 구성됩니다.

## 적용한 규칙

| 구분 | 규칙 | 이 화면에서 |
|---|---|---|
| Typography | `(size − 1) × 0.83vw + 1rem`, size ≤ 1rem 은 px 고정 | 가변: H3 40 · P2 16 · 로고 20 / 고정: P3 14 · 버튼 13 |
| mid-N | `(N − 8) × 100vw / 1920 + 8`, N < 8 고정 | 배너 패딩 48 / 36, 카드 패딩 32 / 28, 카드 간격 32, 텍스트 간격 10 |
| em-N | 요소 폰트 크기 기준 N px | 버튼 13 / 26 (+ 선 1px) |
| 인트로 섹션 높이 | 헤더 제외 화면 높이 | `100dvh − 54px` (미지원 브라우저는 `100vh − 54px`). 이미지는 cover 로 채움 |

## OverlayCard 너비 (데모 패널 · 우측 상단)

- **card width** — `mid` / `vw` 전환. 기본은 mid.
  - mid-N : `(N − 8) × 100vw / 1920 + 8`
  - vw-N : `N × 100vw / 1920` (450 → 23.4375vw)
- **값 (N)** — 기본 450. 옆에 제한 전 공식값이 px 로 표시됩니다.
- **min px / max px** — 켜면 그 사이로 묶습니다 (`max(min, min(공식값, max))`). 기본값 400 / 520, 꺼진 상태로 시작합니다.
- **title text** — OverlayCard 타이틀 문구를 직접 입력해 바꿉니다 (시안 "Lorem ipsum dolor"). 긴 문구에서 줄바꿈 · 카드 높이를 확인할 때 씁니다.
- **heading size** — OverlayCard 타이틀(H3) 크기. 값은 1920 기준 px(시안 40)이고, 가변 공식 `(값 / 14 − 1) × 0.83vw + 1rem` 으로 계산됩니다. 14 이하는 px 고정. 옆에 현재 화면 폭에서의 실제 px 가 표시됩니다.
- 하단 readout 에 실제 카드 너비가 표시되고, min · max 에 걸리면 파란색으로 어느 쪽에 걸렸는지 나옵니다.

## 화면 폭별 카드 너비 (N = 450, min / max 끄기)

| 화면 폭 | mid-450 | vw-450 | 타이틀 줄 수 | 카드 높이 |
|---|---|---|---|---|
| 2560 | 597.3 | 600 | 1 | — |
| 1920 | 450 | 450 | 1 | 312 |
| 1440 | 339.5 | 337.5 | 2 | 355 |
| 1280 | 302.7 | 300 | 2 | 342 |
| 1024 | 243.7 | 240 | 2 | 342 |

- 값이 450 처럼 크면 mid 와 vw 는 거의 같습니다. 차이는 `8 × (1 − 화면 폭 / 1920)` px 로, 1024 에서도 3.7px 뿐입니다.
- 1920 에서 카드 높이가 시안(약 306)보다 6px 큰 것은 H3 · P2 가 공식대로 43.59 · 16.28 이 되기 때문입니다.

## 확인이 필요한 부분

- **blur** — 시안 코드에서 `backdrop-blur 30px` 로 나와 CSS `blur(30px)` 로 넣었습니다. 피그마 Background blur 값이 60 이었다면 맞는 값이고, 30 이었다면 CSS 는 15px 이어야 합니다.
