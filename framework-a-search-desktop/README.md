## 단위 체계 (1rem = 16px)

```css
--us: calc(100vw / 1920);
--page-pad: 2.5vw;                               /* global/desktop-margin-vw = 48 */
--fs-p1: calc((1.5 - 1) * 0.83vw + 1rem);        /* 24px @1920 — 가변 */
--mid-N: calc((N - 8) * var(--us) + 8px);        /* 값 < 8 은 고정 */
```

- **타이포** — 16px(1rem) 을 넘는 건 P1(24, 검색어)과 로고(22)뿐. P3(16)·P4(14)는 고정.
- **spacing** — 맵핑된 `mid-*` 그대로 (검색 바 mid-28 / mid-24, 그리드 상 mid-28 · 하 mid-80 · 행 간격 mid-64,
  카드 정보 mid-16 / mid-2 / mid-4). 배지 padding 은 `em-8 / em-10`, 페이지 번호 최소 크기는 `ch-25`.
- **px 고정** — 헤더 74 (36 / 22), 아이콘 20·24·32·44. 페이지네이션 영역 상하는 두 스타일 모두 `mid-56`.
- **폰트** — 시안이 요소별로 지정한 대로 국문 Noto Sans KR / 영문·숫자 Noto Sans.
