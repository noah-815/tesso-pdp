`index.html` 한 파일과 `assets/`(미디어 이미지, 미디어 마스크, 상품 이미지, 화살표 아이콘)로 구성됩니다.

## 적용한 규칙

| 구분 | 규칙 | 이 화면에서 |
|---|---|---|
| Typography | `(size − 1) × 0.83vw + 1rem`, size ≤ 1rem 은 px 고정 | 가변: H2 52 · P1 18(상품명) · P2 16 · 로고 20 / 고정: P3 14 · P4 13(가격) · C1 12(카테고리) |
| mid-N | `(N − 8) × 100vw / 1920 + 8`, N < 8 고정 | 배너 패딩 64 / 36, 텍스트 간격 16, 카드 패딩 12, 카드 안 간격 16 · 10 · 8 · 2 |
| 상품 썸네일 | mid-112 | 시안 상품 이미지(cover) · radius 2. 비율 1:1(시안) / 4:5 / 3:4 — 너비 기준, 높이가 늘어남 |
| 카드 높이 | 썸네일 기준 hug | 썸네일 높이 + 상하 패딩. 상품 정보가 더 길면 텍스트 아래가 잘리고 화살표는 우하단 유지 |
| 인트로 섹션 높이 | 헤더 제외 화면 높이 | `100dvh − 54px` (미지원 브라우저는 `100vh − 54px`) |
| 토큰 없는 값 | px 고정 | 헤더 54, 텍스트 ↔ 카드 간격 342, 화살표 24, radius 4 / 2 |

## 데모 패널 (우측 상단)

- **card width** — `mid` / `vw` 전환, **값 (N)** 기본 420 (vw-420 = 21.875vw)
- **min px / max px** — 켜면 그 사이로 묶습니다. 기본값 360 / 480, 꺼진 상태로 시작
- **thumbnail** — mid-N 의 N (시안 112). 옆에 실제 너비 × 높이 표시
- **thumb min px** — 썸네일 너비 최솟값. 켜면 `max(최솟값, mid-N)` 으로 그 아래로 줄지 않습니다 (기본 108, 꺼진 상태로 시작). 높이는 선택한 비율대로 따라갑니다.
- **image ratio** — 1:1(시안) / 4:5 / 3:4
- **title text / heading size** — 배너 타이틀 문구와 H2 크기(1920 기준 px, 시안 52)
- **reset** — 모두 시안 값으로

## 확인이 필요한 부분

- **좁은 화면에서 썸네일이 내용보다 짧아짐** — 상품 정보(카테고리 · 상품명 · 가격 · 화살표 24)가 썸네일보다 길어져, 1280 이하에서는 썸네일 아래가 비고 비율을 바꿔도 카드 높이가 그대로입니다. 썸네일 min 값을 두거나 카드 min 너비를 켜는 방향을 검토해야 합니다.
- **텍스트 ↔ 카드 간격 342** — 시안에 토큰 없이 342px 로 들어가 있어 고정으로 두었습니다. 1024 에서 텍스트 영역이 408 까지 줄어듭니다.
- **blur** — 시안 코드에서 `backdrop-blur 20px` 로 나와 CSS `blur(20px)` 로 넣었습니다.
